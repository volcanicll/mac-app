# Mac 软件安利清单

> 收集日常使用的好用软件，吐槽与赞美并存

---

## 💻 写代码的

### Xcode
Apple 官方 IDE，体积大吃内存，启动慢得像蜗牛，但 iOS/macOS 开发离了它不行。爱恨交织的典型。

### Visual Studio Code
微软给的免费午餐，插件多到离谱，什么都能干。只要不嫌它越来越臃肿，就是最好的编辑器。

### Cursor
VS Code 的亲兄弟，加了 AI 能力。Copilot 整合进去了，写代码像作弊，但 subscription 要钱就是了。

### Zed
Rust 写的编辑器，快得飞起。号称 "高性能"，用起来确实丝滑，就是插件生态还在路上。

### Antigravity
Google 出的代码编辑器。极简主义设计，专注编码体验，没有花里胡哨的功能，纯粹干净。

### Android Studio
谷歌家的 IDE，吃内存怪兽。8GB RAM？不存在的，16GB 起步。但 Android 开发绕不过去。

### OpenCode
轻量编辑器，简单粗暴。不想开 VS Code 的时候用这个，秒开。

### Ghostty
终端模拟器的新星，快到没朋友。iTerm2 的有力竞争者，配置简单，颜值在线。

### OrbStack
Docker Desktop 的平替，轻量到感人。内存占用少一半，启动速度快三倍，谁用谁知道。

### Apipost
国产 API 调试工具，Postman 的山寨版但更好用。界面清爽，不用翻墙，国人开发懂国人。

### Codex
代码片段管理器，别再到处找粘贴的代码了。常用片段存起来，一键调用，懒人福音。

---

## 📄 搞文档的

### Obsidian
笔记界的瑞士军刀，本地存储双向链接。Markdown 爱好者的天堂，就是插件能让你玩一天不干活。

### uTools
Everything 搜索 + Alfred 的私生子，快捷启动插件工具箱。按一下快捷键，什么都能干，生产力神器。

### wpsoffice
国产 Office，微软的平替。兼容性还行，广告有点多，但免费也要啥自行车。

---

## 🖼️ 截图贴图

### Snipaste
截图工具的天花板，贴图功能让人上瘾。一旦用上就回不去，F1 截图 F3 贴图，肌肉记忆级别的依赖。

---

## 🌐 上网的

### Google Chrome
浏览器界的霸主，插件丰富到变态。就是吃内存像喝水，开多了电脑风扇起飞。

### Microsoft Edge
Chrome 的换皮版，但微软优化得不错。同步功能强，国产良心（误）。

### Safari
Apple 亲儿子，省电小能手。插件少点但够用，MacBook 续航焦虑的救星。

---

## 📦 压缩传输

### Keka
压缩解压工具，支持全格式。右键一键压缩，比系统自带的强太多了。

### LocalSend
AirDrop 的开源平替，跨平台文件传输。手机电脑互传文件，不用 iCloud，局域网秒传。

### Transporter
苹果家的传输工具，传文件到 iOS 设备用。简单直接，就是功能单一了点。

---

## 🖥️ 显示器控制

### BetterDisplay
外接显示器的救星，HiDPI 开启神器。Mac Mini 用户必备，让 4K 屏不再模糊。

### MonitorControl
外接显示器亮度控制，不用再伸手去按屏幕按钮。系统原生般的体验，免费好用。

### Macs Fan Control
风扇控制工具，MacBook 发热严重的救命稻草。手动控制风扇转速，电脑不再烫手。

### iStat Menus
系统监控全家桶，CPU 内存温度磁盘全显示。菜单栏一站式监控，就是收费有点贵。

---

## 🎵 听歌的

### NeteaseMusic
网易云，情怀大于一切。评论区比歌还精彩，就是广告越来越多了。

## 💬 社交的

### WeChat
微信，工作生活离不开的枷锁。功能臃肿广告多，但你敢卸载吗？

### wechatwebdevtools
微信开发者工具，小程序开发的唯一选择。Bug 多但没得选，忍着用吧。

## 🌐 网络工具

### EasyConnect
深信服的 SSL VPN，公司连内网用。界面丑功能老，但老板让你用你用不用？

### OpenVPN Connect
OpenVPN 官方客户端，稳定可靠。配置文件一导入就能用，老牌 VPN 客户端。
### Antigravity Tools
网络加速工具，具体用途因人而异。懂的都懂。

---

## 🤖 AI & Agent 工具

### LobeHub-Beta
LobeHub 客户端，AI 工具集合平台。探索各种 AI 项目，极客玩具。

### Oh My Agents
管理 Claude Code / Copilot 的 Agent Skills，插件式的 AI 能力扩展。

### Trae CN
Trae 国内版，AI 开发工具。国内网络友好，不需要翻墙。

---

### CC Switch
AI CLI 工具配置管理神器。一键切换 Claude Code、Codex、Gemini CLI 的 API 密钥，多账号党的福音。开源免费，不用再手撸 JSON 配置了。

### Confirmo
Claude Code 的桌面伴侣，轻量级 AI 编码助手。菜单栏常驻，随叫随到，专门配合 Claude Code 用。

### OpenChamber
Claude Code/OpenCode 的多会话 GUI 包装器。多项目并行切换，上下文独立管理，AI 编码工作区的增强版。
